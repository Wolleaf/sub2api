# OpenAI OAuth 模型自动同步（定制版）

在应用容器的 Compose `environment` 中设置：

```yaml
OPENAI_MODEL_SYNC_ACCOUNT_IDS: "1"
OPENAI_MODEL_SYNC_INTERVAL_MINUTES: "15"
```

账号 ID 支持逗号分隔；留空（默认）禁用。间隔范围 5–1440 分钟。
重建应用容器后立即同步一次，此后按间隔执行。无需数据库迁移。

只处理指定的活跃、非影子 OpenAI OAuth 账号，且账号必须使用非空的普通模型白名单。
空白名单表示无限制，不会自动改成有限制；自定义映射及通配符账号跳过。
复用管理端“同步上游支持的模型”的查询和能力元数据逻辑，只追加新模型，保留现有模型。
上游失败不清空列表。获取列表期间凭据或白名单被修改，则延后到下一轮，避免覆盖并发修改。
更新与调度缓存失效事件在同一事务中提交；缓存通过现有 scheduler outbox 更新。

这是模型发现和白名单同步，不安装模型、不变更价格或分组的自定义模型列表。
若分组启用了自定义展示列表，仍需由管理员维护该列表。
现有手动按钮继续可用；自动同步期间手动删除的上游模型会在下一轮重新补回。

日志 `openai_model_auto_sync_ok` 包含账号 ID、新增数量和上游数量；
失败记录 `openai_model_auto_sync_failed` 和阶段，不记录凭据或上游响应正文。
回滚：清空账号 ID 配置并重建应用，或恢复此前的 Compose 和镜像 digest。
已同步的新模型保留，需要还原列表时使用上线前模型映射备份。
